# Agent guidance — php-io-extensions/soloud

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing the API, the C++, or packaging. Open only the concepts the change touches.
2. **SoLoud, 1:1, at its C++ API**, jarikomppa/soloud commit `e82fd32c1f62183922f08c14c814a02b58db1873`. One PHP method = one SoLoud call under its native name and signature, with the native defaults. `SoLoud::X` → `SoLoud\X`; nested scopes are namespaces; free functions are namespace functions; enumerators are `int` constants (class constants for class enums, namespace constants for namespace enums). Public fields are typed properties read and written live, as in C++. `soloud_c.h` is not the surface. See [`.okf/api/surface.md`](.okf/api/surface.md).
3. **Refusals.** The rule, verbatim:
   > A refusal is the extension declining to make the native call. The extension may refuse only when making it would cause (1) memory unsafety — the call would dereference a native object the PHP wrapper no longer validly references; (2) uncatchable process death — SIGSEGV, SIGBUS, abort(), or an ObjC/C++ exception unwinding through Zend frames; (3) VM corruption — PHP code run on a non-PHP thread or illegal engine re-entry. Nothing else justifies a refusal: return codes, nil, clamping, logs, odd but documented results pass through. Every refusal needs a probe on a real build for that exact call. Translation (an NSException AppKit raised, after the native call, turned into AppKitException) is not a refusal. A need of code built on the extension is solved in that code, not here.

   SoLoud's `result` codes pass through as return values. Kept refusals throw `ValueError`; the three `fftfilterinstance-*-state` sites throw `SoLoudException`: [`.okf/architecture/errors.md`](.okf/architecture/errors.md).
4. **Upstream is copied unchanged** into `lib/soloud/` (`include/`, `src/core/`, `src/audiosource/`, `src/filter/`, `src/backend/miniaudio/`, `src/backend/null/`, `LICENSE`). Never edit it. `config.m4` configures it only through upstream's and miniaudio's own defines (`WITH_MINIAUDIO`, `WITH_NULL`, `SOLOUD_NO_ASSERTS`, `MA_NO_RUNTIME_LINKING` on Darwin). A newer SoLoud only from a later upstream commit: replace `lib/soloud/`, rerun `tools/extract.php`, diff `tools/api.json`, regenerate, update tests, bump `PHP_SOLOUD_UPSTREAM_COMMIT` and the version.
5. **Generated code.** `tools/ast.cpp` + `tools/extract.php` turn clang's AST of `lib/soloud/include` into `tools/api.json`. `tools/generate.php` writes `stubs/*.stub.php`, `src/gen/*.cpp` and `src/gen/classes.h` from it and `tools/bindings.php`; `tools/report.txt` lists what it left out. Members with raw buffers are hand-bound in `src/manual/<Group>.cpp`, declared in `bindings.php` `manual`. Change the generator or its config, never `src/gen/` by hand. After generating, run gen_stub (item 9).
6. **The guard.** ext-guard checks every edit to this repo in Claude Code, Cursor and the git hooks. If it blocks an edit, fix the edit; never route around it. `bindings.json` sections: `symbols` — an agent may add entries, validated against SoLoud's headers and the stubs; `glue`, `helpers`, `sites` and `typemap` — only the maintainer (Angel) edits them. A throw on an added line needs a `/* binding:<id> */` marker naming a site, unless it sits inside a `helpers.marshal` function. One marker marks one line: a second line under the same check needs its own site id. The generator emits a check only once its site is in `bindings.json`.
7. **A kept refusal** reads `if (!SOLOUD_PROBE_OFF("<id>") && (<check>))`, carries `/* binding:<id> */` on its throw line, has its `sites` entry, and a probe test in `tests/Probes` that shows the crash with the check off (`soloudChild()` in `tests/Pest.php`, run under libgmalloc on macOS). Probe builds use `./configure --enable-soloud --enable-soloud-probes`; in that build env `SOLOUD_PROBE_OFF=<id>` turns one site's check off and the constant `SOLOUD_PROBES` exists. Probe tests skip on release builds. Never ship a probe build.
8. **C++ on the Zend API.** One PHP object per native address (`SOLOUD_G(boxes)`). PHP deletes what it constructs. Where SoLoud keeps a pointer between objects, the holder keeps the held PHP object alive (`soloud_hold`), and each free handler makes its own deletion safe in any order: [`.okf/architecture/lifetime.md`](.okf/architecture/lifetime.md). A second `__construct()` is refused by `soloud_fresh`.
9. **The stub is the declaration.** Regenerate arginfo with `php84 /opt/homebrew/opt/php@8.4/lib/php/build/gen_stub.php -f stubs` after every generator run, commit stubs and arginfo together. Never hand-edit `*_arginfo.h`.
10. **Callbacks** (`src/callbacks.cpp`): PHP subclasses get C++ trampolines. SoLoud's mixer, pool workers and created threads never enter PHP: they post to the owner thread's queue, raise `EG(vm_interrupt)` and wait. A mixer call not finished within one buffer returns SoLoud's no-op (silence). [`.okf/architecture/callbacks.md`](.okf/architecture/callbacks.md).
11. **Build and test.** Mac: `bash install-macos.sh` into Homebrew `php@8.4` (`php84`) and `php@8.4-zts` (`zhp`). Linux and the Pi: `bash install-debian-trixie.sh`; copy the tree to the Pi with `COPYFILE_DISABLE=1 tar --no-xattrs` so no `._*` files reach gen_stub. Pest v4 at `XDEBUG_MODE=off php -d memory_limit=128M vendor/bin/pest`. Gate a commit on the run's exit code. `php84 scripts/support.php` after a binding change; `tests/CoverageTest.php` checks it. [`.okf/runbooks/build.md`](.okf/runbooks/build.md).
12. **No audible sound.** Engines in tests use `Soloud::NULLDRIVER`. The one real-mixer test plays zeros at volume 0. Never play real audio on the maintainer's machine without asking first.
13. **Durable facts go in `.okf`.** Update the matching concept, bump its `generated.at`, append `.okf/log.md`. The bundle documents the package, never a session.
14. **Version** is `PHP_SOLOUD_VERSION` in `php_soloud.h`: 0.11.0. It moves only past a published tag. `os-families`: linux, darwin.
